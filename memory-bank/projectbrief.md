# Signoff — Project Agreement & Client Portal

## Purpose
A production-ready platform for creating, sending, reviewing, commenting, versioning, and digitally signing project agreements. Supports registered clients and anonymous secure-link access.

## Core requirements
- Admin agreement builder with drafts, templates, pricing, milestones, and terms
- Secure tokenized public agreement links
- Version history that never overwrites signed content
- Comments, change requests, signatures, PDFs, audit trail, notifications
- Extensible for later invoices, payments, and project management
